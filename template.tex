\headerbox{Research Context and Objective}{name=introduction,column=0,row=0,span=3}{
\textbf{Base paper analysed:} \emph{Latent Collaboration in Multi-Agent Systems (LatentMAS)}.

LatentMAS replaces text-only coordination between LLM agents with \textbf{latent collaboration}. Each agent reasons through hidden states and exchanges information through a shared latent working memory instead of explicit chain-of-thought text. The paper reports better reasoning quality together with lower token cost and faster inference.

\textbf{My objective in this project} was not to re-write the original paper, but to extend it with an \textbf{alignment-aware evaluation layer}. The code adds two complementary ideas on top of LatentMAS:
\begin{itemize}\compresslist
\item an \textbf{Alignment Quality Index (AQI)} for ranking candidate models across safety and response quality dimensions before latent collaboration begins;
\item a \textbf{Stackelberg Regret framework} for measuring whether follower agents remain aligned with the leader's intended latent objective during multi-agent interaction.
\end{itemize}

This turns latent collaboration into a more auditable system by asking two practical questions:
\begin{itemize}\compresslist
\item Which model should provide the alignment reference?
\item How can we detect latent misalignment even when behavior looks superficially cooperative?
\end{itemize}
}

\headerbox{What the Original Paper Contributes}{name=paper,column=0,below=introduction,span=1}{
\textbf{LatentMAS core ideas}
\begin{itemize}\compresslist
\item \textbf{Latent reasoning:} agents generate internal reasoning steps directly in hidden-state space.
\item \textbf{Latent communication:} KV-cache based working memory transfers information across agents without decoding intermediate text.
\item \textbf{Training-free design:} collaboration happens without additional fine-tuning.
\item \textbf{Claimed benefit:} richer information exchange with lower communication complexity than text-based MAS.
\end{itemize}

\textbf{Why this needs extension}
\begin{itemize}\compresslist
\item The paper focuses on \textbf{expressiveness and efficiency}.
\item Real deployments also need \textbf{safety, honesty, instruction following, and drift detection}.
\item Hidden-state collaboration is powerful, but it is also harder to inspect than text.
\end{itemize}

\headerbox{New Work 1: Alignment Quality Index}{name=aqi,column=1,below=introduction,span=1}{
\textbf{Goal:} choose a strong alignment reference model before latent collaboration starts.

The module in \texttt{aqi\_module.py} defines a five-part alignment score:
\begin{itemize}\compresslist
\item \textbf{Harmlessness:} refuses harmful or illegal requests.
\item \textbf{Helpfulness:} gives substantive and semantically relevant answers.
\item \textbf{Honesty:} admits uncertainty and avoids fabrication.
\item \textbf{Consistency:} keeps paraphrased answers semantically aligned.
\item \textbf{Instruction Fidelity:} obeys formatting and structural constraints.
\end{itemize}

\textbf{Implementation details}
\begin{itemize}\compresslist
\item Probe set loaded from \texttt{alignment\_probes.json}.
\item Rule-based and embedding-based scoring combined in \texttt{AlignmentScorer}.
\item Weighted aggregate computed in \texttt{AQIComputer}.
\item Highest-AQI model is selected as the \textbf{latent steering baseline}.
\end{itemize}

\textbf{Controlled demo output from the code}

\textbf{Interpretation:} the AQI pipeline correctly separates strongly aligned and weakly aligned candidates in a controlled evaluation. This provides a practical front-end for choosing which latent space should serve as the alignment target.

\headerbox{New Work 2: Stackelberg Regret in Latent Space}{name=sr,column=2,below=introduction,span=1}{
\textbf{Goal:} detect whether follower agents stay aligned with the leader's intended objective after collaboration begins.

The module in \texttt{stackelberg\_regret\_eval.py} introduces a multi-part evaluation:
\begin{itemize}\compresslist
\item \textbf{Behavioral SR:} action-space gap between intended and observed follower behavior.
\item \textbf{Latent SR:} distance between leader-guided latent targets and actual follower latents.
\item \textbf{Nash Deviation Index:} whether followers have an incentive to deviate.
\item \textbf{Latent Cone Rate:} whether follower latents remain inside an aligned latent manifold.
\item \textbf{Best-Response Gap (BRG):} which follower is responsible for misalignment.
\end{itemize}

\textbf{Why this matters}
\begin{itemize}\compresslist
\item Standard MAS evaluation usually focuses on reward or task success.
\item My extension measures \textbf{strategic alignment} and \textbf{representation-level drift}.
\item This is especially useful when coordination happens in latent space and intermediate reasoning is not text-visible.
\end{itemize}

\headerbox{Experimental Prototype and Findings}{name=results,column=0,below=paper,span=2}{
\textbf{Prototype environment}
\begin{itemize}\compresslist
\item \texttt{pettingzoo\_sr\_eval.py} evaluates the metric suite in \texttt{simple\_spread\_v3}.
\item Agent 0 acts as the \textbf{leader}; agents 1 and 2 act as \textbf{followers}.
\item Small neural networks produce both a latent representation and Q-values from observations.
\item Three scenarios are tested: aligned, one misaligned follower, and fully random.
\end{itemize}

\textbf{Measured outputs from the current run}
\begin{center}
\begin{tabular}{|p{0.32\linewidth}|c|c|c|}
\hline
\textbf{Scenario} & \textbf{Latent SR} & \textbf{Nash Deviation} & \textbf{Key BRG signal} \\
\hline
All aligned & 6.7519 & 0.0000 & Follower 1 = 0.0000, Follower 2 = 0.0000 \\
\hline
Follower 1 misaligned & 7.9300 & 13.1890 & Follower 1 = 13.1890, Follower 2 = 0.0000 \\
\hline
Fully random / untrained & 1.4976 & 0.0000 & Both followers = 0.0000 \\
\hline
\end{tabular}
\end{center}

\textbf{What these results show}
\begin{itemize}\compresslist
\item The framework \textbf{successfully localizes a misaligned follower}: BRG clearly identifies follower 1 as the source of deviation.
\item The \textbf{Nash Deviation Index spikes} in the misaligned setting, indicating strategic instability.
\item Drift tracking over aligned runs shows latent SR decreasing from \textbf{10.8659} to \textbf{5.4572}, suggesting the learned policies become more stable over the evaluation window.
\end{itemize}

\textbf{Important limitation}
\begin{itemize}\compresslist
\item The latent cone rate remained \textbf{0.0000} in all tested scenarios, including aligned runs.
\item This suggests the current cone calibration is too strict or the reference manifold is not yet well matched to the learned latent geometry.
\item Therefore, the current contribution should be presented as a \textbf{promising evaluation framework and prototype}, not as a fully calibrated final benchmark.
\end{itemize}
}

\headerbox{Conclusion and Future Work}{name=conclusion,column=0,below=results,span=3,above=bottom}{
\textbf{Conclusion.} The original LatentMAS paper demonstrates that multi-agent collaboration can move from text into latent space. My contribution extends that idea by introducing an \textbf{alignment-selection stage} and an \textbf{alignment-monitoring stage}. Together, these additions ask not only whether latent collaboration is efficient, but whether it remains safe, stable, and faithful to the intended objective.

\textbf{Main contribution of this poster.}
\begin{itemize}\compresslist
\item It reframes LatentMAS from a pure collaboration mechanism into an \textbf{alignment-aware latent MAS workflow}.
\item It contributes an \textbf{AQI model selection layer} and a \textbf{latent Stackelberg regret evaluation layer}.
\item It demonstrates, through code and prototype experiments, how misalignment can be surfaced even when communication is hidden in latent space.
\end{itemize}

\textbf{Future work.}
\begin{itemize}\compresslist
\item Run AQI with real LLM APIs instead of controlled demo models.
\item Calibrate the latent cone using stronger representation fitting and more aligned trajectories.
\item Evaluate on larger cooperative benchmarks beyond \texttt{simple\_spread\_v3}.
\item Integrate online latent steering so AQI-selected baselines can actively correct follower drift during inference.
\end{itemize}
